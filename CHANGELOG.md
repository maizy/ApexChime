# Changelog

## v0.0.1

First release of ApexChime, a portable Windows 11 timer and daily reminder app for sim racing.

- Start multiple timers from ten presets or enter a custom duration or finish time with an optional description.
- Add daily reminders and see both reminders and timers in a live schedule.
- Get click-through alerts that close after 15 seconds and leave the game focused. Preview and choose a Windows sound, one of five bundled chimes, or silent alerts.
- Keep timers and reminders running in the notification area. Enable autostart if desired. ApexChime restores the schedule, settings, and window placement after a restart.
- Download a self-contained executable for Windows x64 or Arm64.
